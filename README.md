# FedAHPIP
### Project Overview

FedAHPiP is an innovative federated learning framework built on the Plato platform, implementing adaptive hierarchical personalization and privacy protection. This project addresses industrial application scenarios in smart manufacturing environments, providing efficient personalized model learning and robust privacy protection capabilities.

This release contains the essential algorithm implementations demonstrating the main innovations of the FedAHPIP method. The complete executable version with full features will be published in future updates.



### Important Notice

**Integration Requirement:**  This code is built on the Plato federated learning platform and must be placed within a Plato project directory structure to run properly.

**Current Status:** This repository currently contains only the core algorithm implementation code. The complete executable version with full functionality will be released in subsequent updates.



### Core Features

#### Privacy Protection

-  Selective homomorphic encryption for critical parameters
- Adaptive hot parameter identification
- Differential privacy for non-critical parameters
- Defense against gradient inversion attacks

####  Personalization

-  Personalized anchoring updates
- Hierarchical protection strategies
- Dynamic parameter importance assessment

####  Performance Metrics

-  Local accuracy tracking
-  Attack evaluation scoring
- Communication overhead analysis



### Supported Datasets

- NEU Surface Defect Dataset
- 50 Types of Car Parts Dataset
- MNIST / Fashion-MNIST
- CIFAR-10 / CIFAR-100
